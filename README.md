# 🐍 Python Study

파이썬 기초부터 차근차근 공부하면서 실습한 코드를 기록하는 저장소입니다.
매일 배운 내용을 직접 코드로 작성해 보고, 꾸준히 커밋하며 성장 과정을 남기고 있습니다.

## 📁 폴더 구조

```
python-study/
├── hello.py                      # 첫 파이썬 코드 (Hello World)
├── sectione-2/                   # 섹션 2 : 변수와 자료형
│   ├── practice-variable.py      # 변수
│   ├── test-variable.py          # 변수 테스트
│   ├── practice-numeric.py       # 숫자형
│   ├── practice-string.py        # 문자열
│   └── pratice-boolean.py        # 불리언
└── sectione-3/                   # 섹션 3 : 연산자와 수식
    ├── practice-operator.py      # 연산자
    ├── practice-간단한 수식.py     # 간단한 수식
    └── practice-숫자 처리 함수.py   # 숫자 처리 함수
```
